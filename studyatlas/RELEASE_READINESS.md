## 0v. Ver.1.6.6 の結果（データ収集の安全性。データ・UI・承認記録の変更なし）

- 通信前の権利チェック：`collector/guard.ts` を新設。すべての自動リクエスト（収集・リンクチェック・調査スクリプト）は `guardedFetch` を通り、通信の前に `decideAccess(url, 取得方法)` が権利レコードを読む。判定は 許可／条件付き（記録された API・データセット・掲載ページに限る）／禁止（権利レコードが自動取得をブロック）／未確認（権利レコードなし・未レビュー）。**不明は許可しない（fail closed）。**
- 取得方法は混ぜない：html（本文）・api・dataset・robots・status-only（HTTPステータスのみ）。HTML 禁止でも CSV は許可、のように区別する。robots.txt が許可していても、権利レコードが禁止なら取得しない（禁止ホストの robots.txt 自体も取得しない）。許可は「取得」の話で、再掲載の許可（reuseStatus・display）とは独立で、緩和していない。
- リンクチェック：禁止・未確認のリンクは通信せず「権利上の理由で未確認」と記録（`skipped`／`unconfirmed`）。403 は引き続き「アクセス拒否」でリンク切れではない。本文を読めないリンクは status-only（内容は未確認）。結果に取得方法と確認日を保持し、旧結果は流用しない（PR の CI で再実行した結果に置き換え）。リンク自体は削除していない。
- 再発防止：TransLink の全 URL（robots.txt 含む）が通信前に拒否されること、Vancouver 交通カードの公式リンクが残ること、誤って取得した 3 ページの内容が使われていないことをテストで保証（モックのみ。TransLink へは接続していない）。ワークフローから UBC への TLS 接続（aia-chain.sh）と、禁止サイトの規約ページ・robots.txt の取得を削除。
- 一時スクリプト：`collector/README.md` に手順を追記。直接の `fetch`／`curl`／`https` と、`*-probe` の一時スクリプト・ワークフローの残存を `tests/guard166.test.ts` が検出する。
- 限界：ガードを経由しない通信（シェルの curl、新しい `node:https` の import、人が操作するブラウザ、`collector/` と `.github/workflows/` の外に置かれたコード）は防げない。テストの走査は一般的なものだけを検出する。権利レコードのない公的機関のサイト（ビザ・学校など）は、記録を作るまでリンクチェックしない。
- 変更なし：承認済み家賃7件とダイジェスト、英国政府 claim 5件、Vancouver・Toronto の気候、Manchester の気候、学校データと比較、Planner、地図、ビザ・医療情報。

## 2. 公開を妨げる問題

1. **データ量**: 6都市のうち Toronto / London / Sydney / Melbourne は公式データ・気候・語学学校がゼロ（概要文＋準備中のみ）。利用可能率は約20–28%、verified は0。
2. **Manchester / Vancouver も大半が未確認**: verified 率は Manchester 約20%・Vancouver 約8%（profile 項目ベース。公式データ点は別に 25 / 16 件が verified）。授業料・語学学校の料金・ホームステイ・シェアの1人あたり料金・食費・通信費・安全は未取得。
3. **古い気候の平年値**: Manchester は 1971–2000、Vancouver は 1981–2010。注意書きは追加済みだが、最新期間（1991–2020）への更新は未完了（上記の理由で保留）。
4. **語学学校情報の裏付け不足**: 表示中の4校（Express English College、International House Vancouver、Sprachcaffe Vancouver、EF Vancouver）も、公式サイトでの住所・コースの照合と営業状況の直接確認は未了（認定リストと公式ページの存在までを確認）。MC Academy・Excel College / UKEC Academy は確認できないため非表示。
5. **地図がデモタイル**: トップページの地図は MapLibre のデモタイル。本番利用に適した商用利用可能なタイル提供元への切替が必要。
6. **リンク検査は一部のみ**: 45リンク中、検証済み24。権利上要求しない9（TransLink・UBC・Met Office サイト）、アクセス拒否2（British Council PDF、IH Vancouver トップ。同サイトの別ページは確認済み）、語の確認なし/不一致10は未検証。定期実行の仕組み（Actions）は追加済み。
7. **利用条件が未確認の出典**: TfGM / University of Manchester は `needs-review`、TransLink / UBC は `restricted`（数値の転載・表示は権利区分に従って制限）。これらの数値を前面に出す機能は法務確認なしに拡大できない。
8. **Planner の「自動」候補が極少**: 対象者・契約期間が確認できた1人あたり料金は University of Manchester の寮1件のみ。語学留学ではほぼ手入力。

## 3. 本PR（Ver.1.3.1）で行った安全化

- 架空のデモ数値（Toronto / London / Sydney / Melbourne の家賃・交通・月額合計）を**公開画面から非表示**（値はデータに残置、都市ページ・比較とも「データ準備中」）。「デモ用サンプル」ラベル付きでも数値が見えていた状態を解消。

- 監査を自動化（`npm run audit`）。公開前チェックのテスト（`tests/releasecheck.test.ts`）を追加。

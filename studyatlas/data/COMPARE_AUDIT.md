# 都市比較のデータ監査（Ver.1.3.8）

目的：Manchester と Vancouver に公式データがあるのに、比較画面で「未取得」に見える原因を切り分け、既存データと比較UIの接続だけを直す。データの値・検証状態（verified）・権利設定・Planner は変更していない。

## 「データがある」と「同じ基準で比べられる」は別
| 項目 | Manchester | Vancouver | 比較画面での扱い（Ver.1.3.8） |
|---|---|---|---|
| 生活費（月額合計） | あり（大学の見積もり・学部生・2026/27・GBP/月・verified） | **なし**（公式の見積もりは未取得。プロフィールは pending） | 参考値のみ（片方の都市のみ）。Vancouver は「未取得」のまま |

## 「未取得」に見えていた原因
1. **住居**：比較画面の第一表示は「学生1人あたりの価格」だけで、市場全体の家賃（Vancouver の CMHC・Manchester の ONS）は「詳しく見る」の中にしかなく、第一表示は「参考料金は準備中」だった。
2. **交通**：Vancouver の運賃は権利設定（TransLink 規約）で数値非表示。詳細行では「公式データなし」と同じ文言になり、「データが無い」と「規約で出せない」が区別できなかった。
3. **判定の粒度**：片方の都市にしか数値が無い項目も「未取得」（データ不足）に丸められ、「比較可能／参考値のみ／未取得」が区別されていなかった。
4. **本当に無いもの**：Vancouver の生活費・学生向け住居（UBC は掲載見合わせ）。これは「未取得」のまま。

## 変更
- `lib/overview.ts`：`compareKey`（住居のみ、学生向け料金が無い都市は表示可能な市場家賃を第一表示に使う）と `availability`（comparable / reference / partial / linkOnly / notYet）。都市ページ用の `keyFigure` は変更なし。
- `data/official/compare.ts`：`missingReason`（数値が無い理由：規約でリンクのみ／掲載見合わせの注記）。表示可否の判定（`isFigureShown`）は変更なし。
- `components/overview/QuickCompare.tsx`：三状態＋「公式リンクのみ」のチップ、第一表示に対象年度、詳細行で数値が無い理由とリンクを表示。デザインは既存のまま。
- 「数値の大小で優劣を示さない」「通貨は換算しない」「未確認は未確認のまま」は従来どおり。

## 未解決のデータ不足
- Vancouver：生活費の公式見積もり、学生向け住居（UBC の許可待ち）、交通の数値（TransLink の同意または専門家確認待ち）。
- Manchester：気候の 1991–2020（Vancouver と共通期間にできない）。
- 学生向け住居の同条件比較（同じ大学・同じ部屋タイプ・同じ年度）は、両都市で揃うデータがまだ無い。
